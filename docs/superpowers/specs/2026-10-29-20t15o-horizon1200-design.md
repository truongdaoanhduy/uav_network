# Controlled 20/15 horizon-1200 design

## Intent
Reduce only the canonical controlled 20-target/15-obstacle episode horizon from 1800 to 1200 steps so the next study is cheaper and less dominated by very long timeout episodes.

## Constraints
- Keep the historical 35-target/25-obstacle profile at 1800 steps for reproducibility.
- Keep 6 UAV, 1 km map, link-budget power +3 dB, buffer/TTL/battery, FP32, E4096/B8192/R1M, BASE/PQL semantics, and HYBRID75 defaults unchanged.
- Keep periodic evaluation at 3,686,400 joint transitions because it is experience-based rather than episode-horizon-based.
- Update output/tag/protocol documentation so no new 20/15 run is mislabeled `steps1800`.
- Do not launch production jobs as part of this change.

## Approach
Use the existing canonical YAML as the single source of the horizon change. The study planner already derives `max_steps` and `steps{max_steps}` dynamically, so no algorithm/source change is needed. Add regression assertions that canonical 20/15 is 1200 while historical 35/25 remains 1800.
