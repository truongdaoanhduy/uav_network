## Scientific flow and POSG

At timestep t, each UAV i has local observation o_i(t) and history h_i(t), including self pose/velocity/battery, local sensor-derived belief, report queue and currently available communication indicators. Decentralized Actor chooses acceleration (ax, ay, az), TX power and a destination (silent, peer, GCS). Centralized Critic may use global state during training only. Policy cannot read target truth, future link outcomes, or remote instantaneous buffer/position.

Positive Bayesian update for a cell with prior p: p_plus = Pd(z)*p / (Pd(z)*p + Pf(z)*(1-p)).
Negative update: p_minus = (1-Pd(z))*p / ((1-Pd(z))*p + (1-Pf(z))*(1-p)).
Prior p0=35/1600 is a density approximation; spatial exclusion zones can change the exact prior.

This is an explicitly NEW partially observable stochastic game and cannot be fairly compared directly to old W&B learning curves without controlling scenario changes.
