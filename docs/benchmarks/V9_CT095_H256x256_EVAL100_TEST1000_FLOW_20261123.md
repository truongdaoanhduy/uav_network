## Exact Eval and Test environment initialization protocol

**Training:** 4096 independent WarpVectorEnv worlds on GPU0, environment runs parallel; GPU1 trains MATD3. Same seed44, replay fraction and update schedule as original V9. Collect full immutable Actor snapshots every 100 vector steps (409,600 total joint environment transitions), including initial/final. Do not select 'best' by training reward or Test.

**Validation (Val100):**
1. After all 20k training episodes, select the prescribed exact-step-grid + final snapshots (keep untouched full snapshots).
2. Spawn two separate GPU workers; CUDA_VISIBLE_DEVICES=0 or 1 so each child uses cuda:0 locally.
3. Alternate checkpoint indices across GPUs. Each worker loads up to 2 Actor checkpoints at a time. For K=2 and Eval=100, instantiate `WarpVectorEnv` with **200 worlds/GPU**, not 4096. No Critic, optimizer or replay; 2 vmap Actor weights in eval() mode.
4. Every checkpoint has **the same 100 seed bank** `[1000000044, ..., 1000000143]`. `evaluate_group` builds `[seed+i for _ in payloads for i in range(100)]`, then calls `vector.reset(seed=seeds)`. This resets belief, report slots, network buffers, energy, UAV positions and obstacles according to the scenario.
5. Evaluate each world deterministically until termination/truncation, up to 1500 steps; record real per-world metrics and validate checkpoint checksums.
6. Select the single best checkpoint by Validation according to the existing BestCheckpoint ranking; never consult Test. Publish exact checkpoint provenance and W&B validation curve.

**Final Test (Test1000):**
1. Load only the validation-selected best Actor. Seed range disjoint from validation/training: `2000000044..2000001043`, 1000 independent worlds total.
2. Launch two GPU subprocesses with fresh `WarpVectorEnv` each. GPU0 = `2000000044..2000000543` (500 worlds); GPU1 = `2000000544..2000001043` (500 worlds). Use physical cap 500 worlds/GPU and `--test-batch-size 0` to select capacity, not the legacy 8-world fallback.
3. Each subprocess creates config from the saved *new* Actor checkpoint, sets `runtime.num_envs = 500`, `runtime.device = cuda` and calls `reset(seed=range(...))`. Run deterministic Actor-only policies with unchanged NoOracle science, PHY/MAC and reward.
4. Verify 1000 unique seeds, all 1000 terminal records, checkpoint SHA256 and non-overlap with training/validation. Aggregate the 1000 outcomes, publish Final Test separately from validation, and retain raw JSON/manifest/checkpoint in Hugging Face + W&B.
